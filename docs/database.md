# Database

The reference DDL is in `Schemas.sql` at the repository root. The Laravel application manages schema evolution through migrations located in `server/HyperionServer/database/migrations/`.

## Tables

### User

Stores registered users.

| Column | Type | Notes |
|---|---|---|
| User_Id | CHAR(36) | UUID, primary key |
| UserName | VARCHAR(30) | |
| UserEmail | VARCHAR(30) | Unique |
| UserSex | ENUM('Male','Female') | |
| UserAge | INT | Nullable |
| HashedPassword | VARCHAR(16) | |

### Event

Stores events created by users.

| Column | Type | Notes |
|---|---|---|
| Event_Id | CHAR(36) | UUID, primary key |
| FK_User_Id | CHAR(36) | Foreign key → User |
| EventName | VARCHAR(30) | |
| EventDesc | TEXT | Nullable |
| EventDate | DATE | |
| EventTime | TIME | Nullable |
| EventVenue | VARCHAR(200) | |
| EventLocation | VARCHAR(255) | Nullable |
| EventStatus | ENUM('Waiting','In Progress','Finished') | |
| EventPrice | DECIMAL(10,2) | |

Deleting a user cascades to their events.

### Book

Junction table linking users to events they have booked.

| Column | Type | Notes |
|---|---|---|
| FK1_User_Id | CHAR(36) | Foreign key → User |
| FK2_Event_Id | CHAR(36) | Foreign key → Event |
| Status | TINYINT(1) | 0 = pending, 1 = confirmed |

Composite primary key (FK1_User_Id, FK2_Event_Id). Cascades on delete from User and Event.

### Ticket

Represents a ticket issued after a booking is confirmed.

| Column | Type | Notes |
|---|---|---|
| Ticket_Id | CHAR(36) | UUID, primary key |
| FK_User_Id | CHAR(36) | Foreign key → User |
| FK_Event_Id | CHAR(36) | Foreign key → Event |
| TicketType | VARCHAR(14) | Nullable |

### Card

Stores bank card information.

| Column | Type | Notes |
|---|---|---|
| BankCard_Id | CHAR(36) | UUID, primary key |
| BankSequence | VARCHAR(16) | Card number |
| BankProvider | VARCHAR(20) | Nullable |
| DatePeremption | DATE | Expiry date |
| CVV | INT(3) | |

### User_Card

Many-to-many association between users and cards.

| Column | Type | Notes |
|---|---|---|
| FK1_User_Id | CHAR(36) | Foreign key → User |
| FK2_BankCard_Id | CHAR(36) | Foreign key → Card |

Composite primary key. Cascades on delete.

### Image

Stores image file paths for events.

| Column | Type | Notes |
|---|---|---|
| Image_Id | CHAR(36) | UUID, primary key |
| ImageUrl | VARCHAR(255) | Relative path on disk |

### Event_Images

Many-to-many association between events and images.

| Column | Type | Notes |
|---|---|---|
| FK1_Event_Id | CHAR(36) | Foreign key → Event |
| FK2_Image_Id | CHAR(36) | Foreign key → Image |

Composite primary key. Cascades on delete.

### Cart

Represents a shopping cart session.

| Column | Type | Notes |
|---|---|---|
| Cart_Id | CHAR(36) | UUID, primary key |
| CartState | VARCHAR(10) | Nullable |
| CreationDate | TIMESTAMP | Defaults to current timestamp |
| CartTotalPrize | DECIMAL(10,2) | Nullable |

### Cart_Event

Many-to-many association between carts and events.

| Column | Type | Notes |
|---|---|---|
| FK1_Cart_Id | CHAR(36) | Foreign key → Cart |
| FK2_Event_Id | CHAR(36) | Foreign key → Event |

Composite primary key. Cascades on delete.

## Entity-relationship summary

```
User ─── creates ──► Event ─── has ──► Event_Images ◄── Image
 │                    │
 ├── books ──────────► Book
 │
 ├── holds ──────────► Ticket
 │
 ├── owns ───────────► User_Card ◄── Card
 │
 └── has ────────────► Cart ──► Cart_Event ◄── Event
```

Draw.io source diagrams are in `docs/diagrams/`.

## Notes

- All primary keys are UUID strings (CHAR(36)) generated by the database with `DEFAULT (UUID())`.
- All tables use `ENGINE=InnoDB`, `utf8mb4` character set, `utf8mb4_unicode_ci` collation.
- Foreign key constraints use `ON DELETE CASCADE ON UPDATE CASCADE` throughout.
